# Review And Verification Fixtures

These fixtures exercise proportional review and evidence-backed closeout.
They keep fresh proof universal while loading specialist procedures only when
scope, uncertainty, risk, delegation, or an explicit audit justifies them.

They validate portable outcomes rather than agent-specific commands:

- tiny changes verify directly without loading the full controller;
- standards/spec review activates independently for acceptance or convention
  uncertainty;
- security review activates for a changed trust boundary or sensitive surface;
- delegated multi-surface work receives full verification and main-agent
  sanity checking;
- review feedback keeps distinct technical classifications without requiring
  repeated response boilerplate;
- specialist results reuse envelope evidence and return findings or route
  deltas to one consolidated closeout.
