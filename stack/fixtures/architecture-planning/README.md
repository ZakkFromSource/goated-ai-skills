# Architecture And Implementation-Planning Fixtures

These fixtures exercise the observable V2 routing contract between descriptive
architecture mapping, prescriptive architecture design, review-only
architecture assessment, and proportional implementation planning.

They intentionally validate outcomes rather than agent-specific commands:

- mapping, design, and review remain separate routes;
- architecture output uses the smallest useful visualization and never requires
  Mermaid by default;
- implementation plans can be inline or durable;
- inline plans can be promoted by reusing discovery, evidence, and decisions;
- each route emits one justified next-step signal instead of reconstructing the
  delivery pipeline.
