# Source-Grounded Research Fixtures

These fixtures exercise the portable `source-grounded-research` contract for
current external investigation. They cover stale and conflicting sources, the
absence of a primary source, read-only inline output, optional durable capture,
and an equivalent single-agent path.

The fixtures describe static conformance outcomes rather than proving live
model behavior, source availability, or retrieval-tool behavior. Live
question-only evaluation remains separate.
